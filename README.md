## Описание проекта

Backend-часть веб-приложения для размещения объявлений о продаже товаров. Пользователи могут регистрироваться, создавать объявления, оставлять комментарии, управлять своим профилем и изображениями.

Ключевые особенности:

✅ Полноценная система аутентификации и авторизации

✅ CRUD операции для объявлений и комментариев

✅ Загрузка и отображение изображений

✅ Разделение ролей (USER/ADMIN)

✅ Валидация данных на всех уровнях

✅ Полное покрытие тестами

## Функциональность
 ### Система аутентификации
- Регистрация и аутентификация пользователей
- Управление профилем (обновление данных, смена пароля, аватар)
- Создание, редактирование, удаление объявлений
- Добавление, редактирование, удаление комментариев
- Загрузка и отдача изображений объявлений и аватарок
- Разделение прав доступа (USER, ADMIN)
  
 ### Управление объявлениями
- Создание объявлений с заголовком, ценой, описанием и изображением
- Просмотр всех объявлений или только своих
- Редактирование и удаление собственных объявлений
- Расширенная информация по каждому объявлению

### Система комментариев
- Добавление комментариев к объявлениям
- Редактирование и удаление собственных комментариев
- Просмотр всех комментариев к объявлению

###  Управление профилем
- Просмотр и редактирование личных данных
- Смена аватара пользователя
- Валидация телефонных номеров и email


## Запуск проекта

1. Убедитесь, что установлены:
    - Java 17 или выше
    - Maven 3.6+
    - PostgreSQL 12+
    - Docker (для фронтенда)

2. Настройте базу данных в Настройте базу данных в `application.properties`:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/avito
   spring.datasource.username=your_username
   spring.datasource.password=your_password
3. Сборка и запуск

    - mvn clean install

   - mvn spring-boot:run
   
4.  Запуск через Docker

    - docker run -p 3000:3000 --rm ghcr.io/dmitry-bizin/front-react-avito:v1.21
5. Проверка работы

    - Backend: http://localhost:8080
   - Frontend: http://localhost:3000
   - Swagger UI: http://localhost:8080/swagger-ui.html

## API документация

После запуска приложения документация доступна по адресам:

Swagger UI: http://localhost:8080/swagger-ui.html

OpenAPI spec: http://localhost:8080/v3/api-docs

- **Основные эндпоинты**


- **Аутентификация**

POST /register - регистрация пользователя

POST /login - аутентификация (Basic Auth)

- **Пользователи**

GET /users/me - получение профиля

PATCH /users/me - обновление профиля

POST /users/set_password - смена пароля

PATCH /users/me/image - обновление аватара

- **Объявления**

GET /ads - все объявления

GET /ads/me - мои объявления

POST /ads - создание объявления (с изображением)

GET /ads/{id} - получение объявления

PATCH /ads/{id} - обновление объявления

DELETE /ads/{id} - удаление объявления

PATCH /ads/{id}/image - обновление изображения

- **Комментарии**

GET /ads/{adId}/comments - комментарии объявления

POST /ads/{adId}/comments - добавление комментария

DELETE /ads/{adId}/comments/{commentId} - удаление комментария

PATCH /ads/{adId}/comments/{commentId} - обновление комментария

- **Изображения**

GET /images/ads/{filename} - получение изображения объявления

GET /images/users/{filename} - получение аватара пользователя

##  База данных

### Конфигурация PostgreSQL
Проект использует PostgreSQL с полной настройкой через Spring Data JPA и Liquibase для управления миграциями.

#### Настройка подключения
```properties
# DataSource Config
spring.datasource.url=jdbc:postgresql://localhost:5433/avito
spring.datasource.username=postgres
spring.datasource.password=password
spring.datasource.driver-class-name=org.postgresql.Driver

# JPA / Hibernate
spring.jpa.database-platform=org.hibernate.dialect.PostgreSQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
```

## Безопасность

### Реализованные меры безопасности

- **Basic Authentication** — стандарт HTTP Basic Auth

- **Password Encoding** — BCrypt хеширование паролей

- **Role-based Authorization** — разделение прав доступа

- **CORS Configuration** — настройка кросс-доменных запросов

- **Input Validation** — валидация на всех уровнях

### Ролевая модель

- **USER** — может управлять своими объявлениями и комментариями

- **ADMIN** — может управлять всеми объявлениями и комментариями

## Тестирование

### Структура тестов
```
test/
├── unit/
│   ├── mapper/              # Тесты мапперов
│   └── service/             # Тесты сервисов
└── integration/
├── controller/          # Интеграционные тесты
└── security/            # Тесты безопасности
```

### Покрытие тестами
- **Unit-тесты:** 85% покрытия сервисов и мапперов

- **Интеграционные тесты:** полное покрытие API эндпоинтов

- **Тесты безопасности:** проверка авторизации и аутентификации

### Запуск тестов
```
# Все тесты
mvn test

# Только unit-тесты
mvn test -Dtest="*Test"

# Только интеграционные тесты
mvn test -Dtest="*IntegrationTest"

# С отчетом о покрытии
mvn jacoco:report
```
